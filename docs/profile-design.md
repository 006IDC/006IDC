# 主页设计约定

- GitHub 账号主页沿用原生外框；README 按品牌横幅、产品方向、AI 主项目、V10 插件、使用反馈排序。
- 复用 006IDC 的橙蓝品牌方向。横幅以静态 SVG 保存浅色、深色两版，通过 picture 选择；正文使用原生文字和链接，保持可复制和辅助阅读。
- 项目名称与功能只取对应已公开仓库的 README；新增私有项目、内部资料或联系方式须另核公开范围。
- 首屏不展示主页技术名、元数据表或内部验证流程。不使用第三方统计图、动态徽章或追踪图片。
- 插件按用途介绍，每项提供明确仓库链接；安装、兼容性、许可与安全细节交由对应项目文档持有。
- 保持窄屏自然换行，不用多列布局或长表格承载项目列表。公开仓库的变更记录与设计说明留在仓内。

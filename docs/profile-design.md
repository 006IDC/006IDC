# 主页设计约定

- 2026-10-23 采用用户选定方向：借鉴 [Peter Steinberger](https://github.com/steipete) 的精选项目展示与 [Anthony Fu](https://github.com/antfu) 的简洁排版，只借鉴信息结构，不复制介绍文字或资产。
- GitHub 账号主页沿用原生外框；README 按品牌名、一句定位、短导航、AI 主项目、V10 扩展、简短反馈指引排序。
- 只使用原生 Markdown 标题、段落、列表与文字链接。字体、颜色、分隔线及浅深主题交由 GitHub 原生样式控制，正文保持可复制和辅助阅读。当前首页不再引用此前的装饰横幅。
- 项目名称与功能只取对应已公开仓库的 README；新增私有项目、内部资料或联系方式须另核公开范围。
- 首屏以 006IDC 为品牌标题，不展示技术元数据表或内部验证流程。不使用第三方统计图、动态徽章、追踪图片、虚构指标或外部字体。
- 插件按用途介绍，每项提供明确仓库链接；安装、兼容性、许可与安全细节交由对应项目文档持有。
- AI 主项目用独立标题与一个短段落解释用途；V10 扩展用单列列表，每项一个入口和一句用途。不重复项目完整 README 或安装步骤。
- 保持窄屏自然换行，不用固定宽度、多列布局或长表格承载项目列表。GitHub 精选卡片沿用五个真实公开项目；公开仓库的变更记录与设计说明留在仓内。
